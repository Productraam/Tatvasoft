========================================================================
   TEMPLE ACCOUNTS & POS SYSTEM - PORTABLE SETUP GUIDE
========================================================================

YES, YOU CAN RUN THIS ON ANY LAPTOP OR COMPUTER!
Follow these simple steps:

STEP 1: PREREQUISITE (ONLY NEEDED ONCE)
----------------------------------------
Ensure Node.js is installed on the computer:
- Download & install Node.js (LTS version) from: https://nodejs.org/
- (Default options during installation are recommended).

STEP 2: EXTRACT THE FILES
----------------------------------------
- Copy "TempleAccountManagement_SourceCode.zip" to any location (Desktop or C: drive).
- Right-click the ZIP and choose "Extract All...".

STEP 3: START THE APPLICATION (1-CLICK)
----------------------------------------
- Open the extracted folder.
- Double-click "Start-Temple-Accounts.bat".

What happens automatically:
1. On first run, it installs required dependencies (~1-2 minutes).
2. It launches the local server.
3. It automatically opens the application in your default web browser at:
   http://localhost:5173/

------------------------------------------------------------------------
TRANSFERRING YOUR DATA BETWEEN COMPUTERS:
------------------------------------------------------------------------
If you have already customized your temple details, created receipt templates, 
or recorded donations and want to move them to the new laptop:

1. On your CURRENT computer:
   - Go to "Temple Settings" -> "Backup & Restore".
   - Click "Export Full Backup (JSON)" to download your backup file.
2. On the NEW laptop:
   - Start the application.
   - Go to "Admin Hub" -> "Backup & Security".
   - Click "Restore Backup" and select your JSON backup file.
   - All your temple settings, receipt templates, donations, and ledgers 
     will be restored immediately!
